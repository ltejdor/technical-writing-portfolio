Every time a notification changes status, Relay calls the bank's system with a signed message called a webhook. The bank's system has to check it before trusting it. Send different messages and watch how the receiver decides. The signatures are real (HMAC-SHA256), calculated in your browser.

What the bank's receiver checks

  • 1
    Was it signed in the last 5 minutes?
    Stops someone from re-sending an old, real message.
  • 2
    Does the signature match the content?
    Proves Relay sent it and nobody changed it.
  • 3
    Is it new?
    Relay may send the same update twice. Process it only once.
